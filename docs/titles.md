# Danh hiệu — mã & danh sách

Mỗi danh hiệu có một **mã**. Icon đặt tên theo mã (vd `G01.png`). Danh hiệu nào không có icon thì bỏ.

Nhóm: **G** = mọi game · **TL** = Tiến lên · **XD** = Xì dách · **PK** = Poker · **LT** = Lô tô · **TD** = Tự do.
📝 = cần lưu thêm dữ liệu mới tính được.
